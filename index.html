Was macht die App?

Request Kalender blendet deine privaten Termine, Feiertage und Schulferien als farbige Punkte über der Tagesleiste im Crew-Dienstplan ein. Alle Daten bleiben lokal auf deinem Gerät.

Einrichtung

  1. Erweiterung in Safari aktivieren: auf dem iPad über das Puzzle-Symbol 🧩 in der Adressleiste, auf dem iPhone über „AA" in der Adressleiste (unten) → Erweiterungen verwalten. Alternativ über Einstellungen → Apps → Safari → Erweiterungen.
  2. Request Kalender einschalten und den Zugriff auf die Dienstplan-Seite erlauben.
  3. Im selben Menü → Request Kalender → Einstellungen öffnen und die iCal/ICS-URL deines Kalenders (z. B. iCloud oder Google) einfügen. Optional dein Bundesland für Feiertage und Schulferien wählen.
  4. Die Dienstplan-Seite neu laden – die farbigen Punkte erscheinen über der Tagesleiste. Tippe auf einen Tag für die Termindetails.

Häufige Fragen

Ich sehe keine Punkte. Prüfe, dass die Erweiterung für die Dienstplan-Seite erlaubt ist und in den Einstellungen eine gültige Kalender-URL hinterlegt ist. Danach die Seite neu laden.

Es funktioniert nicht, wenn ich das CRA über mein Home-Bildschirm-Icon öffne. Safari-Erweiterungen laufen nur im Safari-Browser, nicht in einer zum Home-Bildschirm hinzugefügten Web-App (die öffnet in einem eigenen Vollbild-Modus ohne Erweiterungen). Öffne das CRA direkt in Safari. Für schnellen Zugriff lege dir dort ein Lesezeichen oder einen Favoriten an.

Wo finde ich meine Kalender-URL? Bei Google Kalender: Kalendereinstellungen → „Kalender integrieren" → „Geheime Adresse im iCal-Format" (nicht die öffentliche — dann muss der Kalender nicht öffentlich geschaltet werden). Bei Apple iCloud: in der Kalender-App auf „Kalender freigeben" → „Öffentlicher Kalender" aktivieren → „Link freigeben"; die iCloud-URL enthält einen geheimen Token und ist trotz des Namens nicht auffindbar. Behandle die URL in beiden Fällen wie ein Passwort.

Werden meine Daten übertragen? Nein. Es gibt keine Server des Entwicklers. Details in der Datenschutzerklärung.
